# FX Route Planner

Keep all four files in the same folder:

- fx-board.html   main page: live rates, summary, all routes, fees and SWIFT, checks, sources
- fx-inputs.html  second page: provider rates, fees, risk, fallback rates, self-check, methodology
- fx-core.js      shared engine (sources, consensus mid, routes, fees, self-check)
- fx-theme.css    shared look (Cambria, pill shapes)

Open fx-board.html in Edge or Chrome, or copy the folder into static/ in the FastAPI app.
Settings are saved in the browser (localStorage). Illustrative only.
